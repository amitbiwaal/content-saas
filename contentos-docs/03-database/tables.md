# Tables

> **Status:** v2.0 — complete. The physical table specification for PostgreSQL 17, derived from `02-domain-design/`.
> **Authority rule:** where this document and a Phase 2 domain document appear to disagree, Phase 2 wins and this document is corrected. No table, column, or constraint here introduces a business rule that Phase 2 did not already state.

## 1 · Conventions applied to every table

Stated once; not repeated per table. A table deviates only where its specification says so explicitly.

### 1.1 Standard column set

```sql
id           UUID        PRIMARY KEY DEFAULT uuidv7()   -- PostgreSQL 17: uuidv7() native
tenant_id    UUID        NOT NULL                       -- the workspace (ADR-017)
organization_id UUID     NOT NULL                       -- commercial boundary, denormalized
created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
updated_at   TIMESTAMPTZ NOT NULL DEFAULT now()
created_by   UUID        NULL REFERENCES users(id)      -- NULL = system actor
updated_by   UUID        NULL REFERENCES users(id)
version      INTEGER     NOT NULL DEFAULT 1             -- optimistic concurrency (mutable roots only)
deleted_at   TIMESTAMPTZ NULL                           -- soft-delete tables only
```

| Rule | Detail |
|---|---|
| Identifiers | UUID v7 — time-ordered, so B-tree insertion stays sequential and index bloat is avoided. Generated by the application for outbox correlation; `DEFAULT uuidv7()` is the fallback |
| Timestamps | `TIMESTAMPTZ` in UTC, always. `TIMESTAMP` without zone is prohibited |
| Enums | `TEXT` + `CHECK`, never native `ENUM` (see `README.md` §Naming) |
| Money | `NUMERIC(12,4)` — never `float`. Costs in USD, credits in whole units |
| Text | `TEXT`; length limits expressed as `CHECK`, not `VARCHAR(n)` |
| Booleans | Non-nullable with an explicit default |
| JSONB | Documented shape per column; validated by `CHECK` where it carries an invariant |
| `updated_at` | Maintained by trigger `set_updated_at()`, applied to every mutable table |
| Append-only tables | No `version`, no `deleted_at`, no `updated_*`; `UPDATE`/`DELETE` revoked at the role level |

### 1.2 Tenancy and RLS (applied to all but the five documented exceptions)

```sql
ALTER TABLE <t> ENABLE ROW LEVEL SECURITY;
ALTER TABLE <t> FORCE ROW LEVEL SECURITY;   -- applies to the table owner too

CREATE POLICY <t>_tenant_isolation ON <t>
  USING      (tenant_id = current_setting('app.tenant_id', true)::uuid)
  WITH CHECK (tenant_id = current_setting('app.tenant_id', true)::uuid);
```

`current_setting(..., true)` returns `NULL` when unset, so an unset tenant context yields **zero rows** rather than all rows — the property asserted by a dedicated test. `WITH CHECK` is what blocks the reverse leak: writing a row carrying another tenant's `tenant_id`.

### 1.3 Deletion semantics

| Strategy | Behaviour |
|---|---|
| **Soft delete** | `deleted_at` set; repositories filter; purge after 30 days |
| **Terminal state** | Row retained; `state`/`status` moves to `cancelled`/`revoked`/`unpublished` |
| **Append-only** | No delete path; retention policy only |

Foreign keys are `ON DELETE RESTRICT` by default. The **only** `CASCADE` in the schema is `evidence_embeddings.evidence_id`, because embeddings are derived and rebuildable.

## 2 · Identity and tenancy

### `users` — RLS exception

**Purpose:** global identity; a user exists above and across organizations.
**Aggregate:** `User` (root). **Tenant strategy:** none — above the boundary.

| Column | Type | Rules |
|---|---|---|
| `id` | UUID PK | |
| `email` | CITEXT NOT NULL | `UNIQUE`; case-insensitive |
| `name` | TEXT NOT NULL | `CHECK (length(btrim(name)) BETWEEN 1 AND 120)` |
| `status` | TEXT NOT NULL DEFAULT `'active'` | `CHECK (status IN ('active','deactivated','erased'))` |
| `email_verified` | BOOLEAN NOT NULL DEFAULT false | |
| `mfa_state` | JSONB NOT NULL DEFAULT `'{}'` | `{ enrolled, factors[] }`; secrets held by the auth provider, never here |
| audit + `deleted_at` | | |

**RLS:** exception. Policy: a user may read their own row; organization admins may read rows of users holding a membership in their organization. **Constraints:** `UNIQUE (email)`. **Size:** 10⁵–10⁶. **Writes:** low. **Reads:** very high (every request; cached). **Lifecycle:** `active → deactivated → erased`; erasure anonymizes `email`/`name` and retains the row so authorship references survive.

### `organizations` — RLS exception

**Purpose:** commercial and administrative boundary (ADR-017). **Aggregate:** `Organization` (root).

| Column | Type | Rules |
|---|---|---|
| `id` | UUID PK | |
| `slug` | TEXT NOT NULL | `UNIQUE` globally; `CHECK (slug ~ '^[a-z0-9-]{3,48}$')`; immutable |
| `name` | TEXT NOT NULL | `CHECK (length(btrim(name)) BETWEEN 1 AND 120)` |
| `status` | TEXT NOT NULL DEFAULT `'active'` | `CHECK (status IN ('active','past_due','suspended','pending_closure','closed'))` |
| `plan_limits` | JSONB NOT NULL | `{ maxWorkspaces, maxMembers, retentionDays, ssoEnabled }` — projection from Commerce, never authored here |
| `billing_ref` | TEXT NULL | Opaque Commerce pointer |
| `version` | INTEGER NOT NULL DEFAULT 1 | |
| audit + `deleted_at` | | |

**RLS:** exception; readable only by members. **Size:** 10⁴–10⁵. **Writes:** very low. **Reads:** high (cached). **Lifecycle:** per `02-domain-design/organizations.md`.

### `organization_memberships` · `sso_configurations` · `verified_domains` — RLS exceptions

| Table | Key columns | Critical constraints |
|---|---|---|
| `organization_memberships` | `organization_id`, `user_id`, `role`, `status`, `expires_at` | `UNIQUE (organization_id, user_id)`; `CHECK (role IN ('org_owner','org_admin','billing_owner'))`; `CHECK (status IN ('invited','active','revoked'))` |
| `sso_configurations` | `organization_id`, `protocol`, `config JSONB`, `enforced` | `UNIQUE (organization_id)`; `CHECK (protocol IN ('saml','oidc'))`; `config` holds references, never secrets |
| `verified_domains` | `organization_id`, `domain`, `verified_at`, `method` | **`UNIQUE (domain)` globally** — one organization per domain, enforced by the database (`organizations.md` rule 9) |

**These five tables are the complete and closed set of RLS exceptions.** Adding a sixth requires an ADR.

### `workspaces`

**Purpose:** the isolation boundary; `workspaces.id` **is** `tenant_id`. **Aggregate:** `Workspace` (root).

| Column | Type | Rules |
|---|---|---|
| `id` | UUID PK | Referenced as `tenant_id` everywhere downstream |
| `organization_id` | UUID NOT NULL FK → `organizations(id)` RESTRICT | Fixed at creation |
| `slug` | TEXT NOT NULL | `UNIQUE (organization_id, slug)`; immutable |
| `name` | TEXT NOT NULL | `CHECK (length(btrim(name)) BETWEEN 1 AND 80)` |
| `status` | TEXT NOT NULL DEFAULT `'active'` | `CHECK (status IN ('active','suspended','archived','pending_deletion'))` |
| `settings` | JSONB NOT NULL DEFAULT `'{}'` | `{ brandVoice, gateThresholds, routing, locale, approval, retention }` |
| `version`, audit, `deleted_at` | | |

**RLS:** keys on `id = current_setting('app.tenant_id')`, plus an org-scoped read policy so an org admin can list workspaces without entering them. **Size:** 10⁵. **Writes:** low. **Reads:** very high (cached per request). **Soft delete:** yes, 30-day purge.

### `workspace_memberships` · `workspace_settings_history`

| Table | Key columns | Critical constraints | Profile |
|---|---|---|---|
| `workspace_memberships` | `tenant_id`, `user_id`, `role`, `status`, `invited_by`, `expires_at` | `UNIQUE (tenant_id, user_id)`; `CHECK (role IN ('owner','admin','editor','viewer'))`; `CHECK (status IN ('invited','active','revoked'))` | 10⁶; medium write; very high read |
| `workspace_settings_history` | `tenant_id`, `changed_keys TEXT[]`, `before JSONB`, `after JSONB`, `changed_by` | **Append-only** | 10⁶; low write; low read |

**Last-owner protection** (`workspace.md` rule 5) cannot be a declarative constraint — it is a cross-row rule over a filtered set. It is enforced by a `BEFORE UPDATE OR DELETE` trigger that counts remaining active owners and raises `WS_LAST_OWNER` (§8).

### `source_documents`

| Column | Type | Rules |
|---|---|---|
| `tenant_id` | UUID NOT NULL | |
| `provenance` | JSONB NOT NULL | `{ url, retrievedAt, method, contentHash }` — **every field mandatory** |
| `fingerprint` | TEXT NOT NULL | Normalized-content hash |
| `archive_ref` | TEXT NULL | R2 object key for the raw document |
| `trust` / `freshness` | JSONB NULL | `{ value, method, computedAt }` — labeled estimates |
| `status` | TEXT NOT NULL | `CHECK (status IN ('retrieved','parsed','indexed','unreachable','excluded'))` |

**Provenance enforcement** (`research.md` rule 1):

```sql
CONSTRAINT ck_source_documents__provenance_complete CHECK (
  provenance ? 'url' AND provenance ? 'retrievedAt' AND
  provenance ? 'method' AND provenance ? 'contentHash' AND
  (provenance->>'retrievedAt')::timestamptz <= now()
)
```

**Size:** 10⁸. **Writes:** high. **Reads:** medium.

### `evidence_items` — the grounding anchor

**Purpose:** the atomic unit of grounding; outlives every run and article that used it. **Append-only.**

| Column | Type | Rules |
|---|---|---|
| `tenant_id` | UUID NOT NULL | |
| `source_id` | UUID NOT NULL FK → `source_documents(id)` RESTRICT | |
| `provenance` | JSONB NOT NULL | Same completeness `CHECK` as above |
| `fingerprint` | TEXT NOT NULL | `UNIQUE (tenant_id, fingerprint)` — deduplication identity (`research.md` rule 5) |
| `excerpt_range` | INT4RANGE NOT NULL | Offsets into the archived source |
| `excerpt` | TEXT NOT NULL | `CHECK (length(excerpt) <= 5000)` |
| `status` | TEXT NOT NULL DEFAULT `'active'` | `CHECK (status IN ('active','superseded','retracted'))` |
| `superseded_by` | UUID NULL FK → `evidence_items(id)` | `CHECK ((status = 'superseded') = (superseded_by IS NOT NULL))` |

Additional: `UNIQUE (tenant_id, source_id, excerpt_range)` — the same excerpt cannot be stored twice from one source.

**Size:** 10⁹ — the largest non-time-series table; partitioned by `(tenant_id, created_at)` at S3. **Writes:** very high. **Reads:** very high. **Deletion:** append-only; retention hard-deletes only when no active `citation_anchors` reference the row, otherwise it is retracted and retained.

### `evidence_embeddings` · `extracted_entities` · `entity_mentions`

| Table | Key columns | Critical constraints | Profile |
|---|---|---|---|
| `evidence_embeddings` | `tenant_id`, `evidence_id` FK **CASCADE**, `chunk_index INT`, `embedding VECTOR(n)`, `model TEXT` | `UNIQUE (evidence_id, chunk_index)`; `tenant_id` denormalized so ANN queries filter without a join | 10⁹; very high write |
| `extracted_entities` | `tenant_id`, `type`, `canonical_name` | `UNIQUE (tenant_id, type, canonical_name)` | 10⁸ |
| `entity_mentions` | `tenant_id`, `entity_id`, `evidence_id` | `UNIQUE (entity_id, evidence_id)` | 10⁹ |

The embedding dimension `n` is fixed by the model choice (OQ-11); the column is written only after that resolves, and a model change is a new column plus backfill, never an in-place redefinition.

### `citation_anchors` — the grounding chain

| Column | Type | Rules |
|---|---|---|
| `tenant_id`, `revision_id` | UUID NOT NULL | FK → `article_revisions(id)` RESTRICT |
| `claim_text` | TEXT NOT NULL | |
| `offsets` | INT4RANGE NOT NULL | Position within the rendered section |
| `evidence_id` | UUID NULL FK → `evidence_items(id)` **RESTRICT** | Evidence in use cannot be deleted |
| `supported` | BOOLEAN NOT NULL | |

**The invariant, in schema** (`articles.md` rules 12–13):

```sql
CONSTRAINT ck_citation_anchors__grounding CHECK (
  (supported = true  AND evidence_id IS NOT NULL) OR
  (supported = false AND evidence_id IS NULL)
)
```

A dangling anchor is physically impossible: either the claim is supported and points at real evidence, or it is explicitly flagged unsupported. **Size:** 10⁹. **Writes:** very high.

| `url_registry` | `tenant_id`, `project_id`, `article_id`, `url`, `gsc_property`, `ga_property`, `state`, `tracking_since` | `UNIQUE (tenant_id, url)`; `CHECK (state IN ('unconnected','tracking','paused','stopped'))` | 10⁷ |

**The Explainability Envelope requirement, in schema** (ADR-009, `analytics.md` rule 11):

```sql
CONSTRAINT ck_optimization_actions__envelope CHECK (
  envelope ? 'recommendation' AND envelope ? 'reason' AND
  envelope ? 'expected_impact' AND envelope ? 'confidence' AND
  jsonb_typeof(envelope->'evidence') = 'array' AND
  jsonb_array_length(envelope->'evidence') > 0
)
```

A recommendation without evidence cannot be persisted. The identical constraint applies to `refresh_plans`.

## 8 · Platform and infrastructure

### `outbox_events` (ADR-020)

**Purpose:** guarantees an event exists if and only if its transaction committed. **No foreign keys by design** — it must be writable alongside any table and must survive deletion of the aggregate it describes.

| Column | Type | Rules |
|---|---|---|
| `id` | BIGSERIAL PK | Publication order |
| `event_id` | UUID NOT NULL | `UNIQUE` — the consumer dedupe key |
| `tenant_id`, `organization_id` | UUID NOT NULL | |
| `event_type`, `event_version` | TEXT / INT NOT NULL | |
| `aggregate_type`, `aggregate_id` | TEXT / UUID NOT NULL | Ordering key |
| `correlation_id`, `causation_id` | UUID | Chain reconstruction |
| `payload` | JSONB NOT NULL | Identifiers and scalars only — **never content, credentials, or PII** |
| `occurred_at` | TIMESTAMPTZ NOT NULL | |
| `published_at` | TIMESTAMPTZ NULL | The one mutable column; `NULL` = pending |

**RLS:** tenant policy applies to application roles; the relay role holds a documented, audited cross-tenant read policy (`16-security/rbac.md`). **Size:** 10⁹, pruned at 30 days. **Writes:** very high.

### `processed_events` · `audit_log` · `idempotency_keys`

| Table | Key columns | Critical constraints | Profile |
|---|---|---|---|
| `processed_events` | PK `(consumer_group, event_id)`, `processed_at` | The PK **is** the exactly-once-effect guarantee | 10⁹; pruned with bus retention |
| `audit_log` | `tenant_id`, `organization_id`, `actor_id`, `action`, `target_type`, `target_id`, `before JSONB`, `after JSONB`, `correlation_id` | **Append-only; `UPDATE`/`DELETE` revoked at role level** | 10⁹ |
| `idempotency_keys` | `tenant_id`, `endpoint`, `key`, `response JSONB`, `expires_at` | `UNIQUE (tenant_id, endpoint, key)` — the constraint, not application logic, makes concurrent duplicate submissions safe | 10⁸; 24h TTL |

|---|---|---|

| `credit_ledger_entries` | `CHECK (entry_type IN ('grant','consumption','refund','adjustment','expiry'))`; **append-only, `UPDATE`/`DELETE` revoked**; corrections are compensating rows | 10⁹ |
| `ai_call_costs` | `tenant_id`, `article_id`, `task_type`, `model`, `prompt_version`, `prompt_tokens`, `completion_tokens`, `cost_usd NUMERIC(12,4)`, `cache_hit`; append-only | 10⁹ |

**Commerce scope note.** Only the Commerce tables that Phase 1 and Phase 2 already depend on appear here. Inventing them now would contradict the rule against inventing entities and would conflict with that document.

### Read model tables

`article_list_view`, `project_board_view`, `workspace_switcher_view` — materialized **tables** maintained by event consumers, each carrying `tenant_id`, RLS, and a `projected_through BIGINT` watermark referencing `outbox_events.id`. Rebuildable by replay; a stale projection is surfaced as stale rather than served as truth.

## 9 · Invariant → constraint traceability

Every Phase 2 invariant, and how it is enforced. This table is the acceptance criterion for the schema.

| Phase 2 invariant | Mechanism |
|---|---|
| Workspace belongs to one organization | FK `RESTRICT` |
| Workspace slug unique per org, immutable | `UNIQUE (organization_id, slug)` + trigger blocking update |
| One membership per user per workspace | `UNIQUE (tenant_id, user_id)` |
| **Last-owner protection** | **Trigger** (cross-row count — not declarable) |
| Domain claimed by one organization | `UNIQUE (domain)` |
| Project belongs to one workspace | FK `RESTRICT` |
| One open task per type per article | Partial unique index |
| One active calendar item per article | Partial unique index |
| Template versions immutable | Append-only + `UPDATE` revoked |
| **Evidence requires complete provenance** | `CHECK` on JSONB keys + `NOT NULL` |
| Evidence deduplication | `UNIQUE (tenant_id, fingerprint)` |
| Evidence immutable | Append-only; `superseded_by` self-FK |
| Keyword metrics nullable, never zero-filled | Nullable columns (no `DEFAULT 0` anywhere) |
| Discovery artifacts carry `as_of` | `NOT NULL` |
| Article belongs to one project | FK `RESTRICT` |
| Revisions monotonic, immutable | `UNIQUE (article_id, revision_number)` + append-only |
| **Writing requires an approved outline** | `CHECK` on `articles.status` vs `approved_outline_id` |
| **Every claim grounded or flagged** | `CHECK` on `citation_anchors` |
| Evidence in use cannot be deleted | FK `RESTRICT` from `citation_anchors` |
| One report per analyzer per version | `UNIQUE (article_id, revision_number, analyzer)` |
| Verdict has exactly three values | `CHECK` |
| Verdict records threshold snapshot | `NOT NULL` |
| Scores are 0–100 with confidence | `CHECK` range constraints |
| **Package requires an authorizing verdict** | `NOT NULL` FK to `gate_verdicts` |
| **Publish idempotency** | `UNIQUE (idempotency_key)` |
| One live record per article per target | Partial unique index |
| One live URL per target | `UNIQUE (target_id, url)` |
| Credentials never stored in domain tables | **No column exists** to store them |
| Snapshot revisions coexist | `UNIQUE (url_id, window_start, granularity, as_of)` |
| Completeness mandatory | `NOT NULL` |
| One proposed action per type per article | Partial unique index |
| One running refresh per article | Partial unique index |
| **Explainability Envelope with evidence** | `CHECK` on JSONB shape and array length |
| Ledger and audit immutable | Role-level `UPDATE`/`DELETE` revocation |
| Exactly-once event effect | PK `(consumer_group, event_id)` |
| Request idempotency | `UNIQUE (tenant_id, endpoint, key)` |
| Tenant isolation | RLS `USING` + `WITH CHECK` on every table |

### Invariants that cannot be enforced declaratively

| Invariant | Why | Mechanism |
|---|---|---|
| Last-owner protection (workspace and org) | Cross-row count over a filtered set | `BEFORE UPDATE OR DELETE` trigger raising `WS_LAST_OWNER` / `ORG_LAST_OWNER` |
| Workspace quota under plan limits | Compares a count against a JSONB projection on another table | Application check inside the creating transaction + advisory lock on `organization_id` to close the race |
| Revise-loop cap | Requires counting outline versions and reading workspace policy | Application, in the aggregate; the count is queryable for audit |
| Assignee must be an active workspace member | Cross-table state check on every write | Application + a periodic reconciliation job that unassigns orphaned tasks |
| Ranking-change confidence window | Statistical, not relational | Application in `RankingChangeDetector` |
| Coverage sufficiency before outline approval | Requires vector similarity and counts | Application in `CoverageValidator` |
| Settings apply only to runs started after change | Temporal semantics | Snapshot at run start, stored on the run |

Each is documented rather than silently trusted, and each has a corresponding integration test (`10-testing/integration-testing.md`).
